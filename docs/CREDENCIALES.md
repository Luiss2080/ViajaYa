## 📝 Notas Importantes

- ✅ Las contraseñas son de **4 dígitos numéricos**

- ✅ Para crear nuevos usuarios, contacta al administrador del sistema

## 🔄 Proceso de Autenticación

1. **Ingresa el nombre de usuario** (sin distinción entre mayúsculas/minúsculas)
2. **Ingresa los 4 dígitos de la contraseña** en los campos correspondientes
3. **Presiona "INGRESAR"** para acceder al sistema
4. **El sistema validará** las credenciales automáticamente

## 🚨 Solución de Problemas

- Si no puedes acceder, verifica que estés usando las credenciales exactas
- Asegúrate de completar todos los 4 dígitos de la contraseña
- Si persiste el problema, reinicia la aplicación
